# R013: проверка контраста и размера текста

Проверено 2026-11-08 в Windows, Microsoft Edge 157.0.4341.42, Node 24.18.0. Изменены только разрешённые CSS: основной файл и history, route, training, player, ear, harmony, tracks. Внешний UI_UX_AUDIT_2026-11-08.md не изменён.

## Метод

`node test-results/contrast-qa.mjs before` и `node test-results/contrast-qa.mjs after` открывают собственный Vite source preview на 4186 и завершают созданные ими сервер/Edge. Пользовательский сервер 4173 не использовался и не останавливался. Режим before подменяет только загрузку CSS точными предварительными копиями через Vite plugin, не переписывая рабочие исходники.

Компонентный стенд использует настоящие UI controllers и синтетические учебные данные: развёрнутую историю с вопросами/сводкой, пресет, просмотр импорта, включённую кнопку восстановления, задания, плеер, слуховую сводку, остановленный маршрут, гармонию и metadata отсутствующего локального файла. Цвета получены из getComputedStyle с учётом альфа-композиции фонов предков; контраст рассчитан по относительной яркости sRGB. Для SVG text использован fill. Декоративные элементы и disabled controls в выборку не включены.

## Пределы

Это выборочная проверка текстовых targets настоящих компонентов, а не полная сертификация WCAG или полная навигация производственного приложения. Данные стенда синтетические; пользовательская база и реальные файлы не затронуты. Координаты основного грифа представлены небольшим SVG probe с действующими CSS, координаты answer-board проверены на настоящем SVG тренажёра. Не проверялись физический звук, экранные читалки, все возможные тексты ошибок, системное масштабирование и все состояния приложения. Полная регрессия приложения остаётся отдельной проверкой root.

`git diff --check` для восьми CSS завершился без ошибок пробелов; Git сообщил только предупреждения нормализации LF/CRLF.

Компоненты личных дорожек в стенде использовались только для выборочной CSS-проверки будущих файлов. Эти targets не подтверждают продуктовую приёмку R-019; аудиовход R-020 не входил в этот стенд.
