## Музыка и настоящий PCM

Независимый басовый эталон: **C2/E2/G2/E2 → F1/A1/C2/A1 → G1/B1/D2/B1 → C2/E2/G2/E2**. Pad: C3/E3/G3 → F3/A3/C4 → G3/B3/D4 → C3/E3/G3. Проверка не вычисляет ожидаемый ответ тем же генератором, который испытывает.

При 120 BPM без отсчёта такты начинаются в0/2/4/6 с, четверти через 0.5 с, конец в 8 с. Реальный OfflineAudioContext даёт три независимых канала, 44.1 кГц, 8.1 с с хвостом. RMS-окно 5 мс извлекает 16 начал баса/клика; басовые Hz измеряются по samples. Например C2 **65.406394 Гц**, F1 **43.653531 Гц**, G1 **48.999428 Гц**. Допуск начала 20 мс и частоты 0.1 Гц относится к методу проверки, не к физическому аудиовыходу.

Pad проверен проекцией на независимые три частоты каждого аккорда; неправильная F♯3-компонента существенно слабее. Все три конечных канала имеют tailRms 0. Один непрерывный pad не обязан давать отдельное RMS-начало на каждой смене: смены проверяются частотным содержимым тактов.

Четыре count-in четверти сдвигают музыку на 2 с и дают 20 кликов за весь finite-проход. Два цикла дают 32 басовых начала без второго отсчёта/лишней ноты на границе. Initial mute изолирует каждый канал; mid-cycle mute pad 2–4 с, баса 4–6 с и изменение клика оставляют сетку других голосов. Нулевой сигнал выключенного канала не выводится из одной настройки GainNode — измеряется из PCM.

## Live-clock и управление

Live-сценарии проверяют ненулевой настоящий анализатор, actual cursor против ещё будущего lookahead, отмену голосов, три restart и тишину после stop. Дробная пауза на transportBeat **1.69** замораживает часы; продолжение восстанавливает хвосты и идёт по регулярным четвертям, без дублированной доли. Ранняя пауза до future start сохраняет все четыре отсчётные доли.

При 220 BPM finite-снимок `finishing` получен в actual audioTime **4.312 с**, finishAt **4.398636 с**: последний такт ещё видим. `finished` наступил после аудиоконца, не из раннего scheduler callback. Преднамеренная блокировка главного потока 750 мс вызывает timing-паузу с понятным текстом и явным продолжением, а не догоняющий пакет старых нот.

UI отдельно проверил четыре аккорда / 16 нот, блокировку структурных настроек при доступном live-микшере, actual highlight, Space/Escape с guards input/button, ошибочный BPM/восстановление, узкую ширину 390, уход из раздела и native hidden. Настоящее скрытие выполняется отдельным Edge/CDP `noDefaults:true` с активацией реальной вкладки, без подмены document.hidden. Возврат требует явного продолжения. Root просмотрел `p7-harmony-desktop.png`, `p7-harmony-narrow.png`, `contrast-after-history-390.png`: контролы читаемы, горизонтального расширения документа в проверенном узком состоянии нет. Это выборочный просмотр, не полная мобильная/скринридерная приёмка.

## Данные и исправления

Схема 4 добавляет настройки harmony/раздел в preferences и presets. Настоящие базы 1/2/3 и буквальные старые JSON проходят миграцию, сохраняя screen/manual/ear/route и исходные события/даты. Invalid legacy отменяет upgrade без сброса. Preset/reload и download→preview→подтверждённая замена дают точные настройки микшера. Native quota создаётся CDP только на тестовом origin, физический диск не переполняется; abort после успешного put проверяется отдельно. Перезапуск всего тестового Edge подтверждён, `staticServerRestart:false` при external reuse не выдаётся за новый restart сервера.

Дополнительно исправлено и проверено release-регрессией:

- Reveal произвольного интервала сохраняет написание: ♭5 от C показывает G♭, а не F♯; формулировка/подпись/ответ согласованы.
- Изменение count через blur/change архивирует реальные действия старой серии под её ID/планом. Новая серия получает свой ID/количество; переходы к вопросу/итогу и разделу сохраняют осмысленный фокус.
- Неверная неактивная лестница не блокирует обычный плеер/канонические preferences; при активной лестнице неверный диапазон по-прежнему отклоняется.
- Ручной черновик фиксирует исходные материал, время и runtime epoch при вводе. Сохранение старой заметки после нового запуска не расходует длительность новой практики. В сопровождении материал явно подписан C–F–G–C; длительность относится к эталону без пауз/отсчёта.
- Досрочное завершение маршрута не подписывается полным прохождением 10 минут: сохраняется фактическое время и соответствующий текст.
