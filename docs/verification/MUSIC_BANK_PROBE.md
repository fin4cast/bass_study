# Проба свободного музбанка P10-00

Дата: **2026-11-08**, Europe/Moscow. Основание — [D-029](../DECISIONS.md#d-029), [R-024](../REQUIREMENTS.md#r-024), [P10](../PLAN.md#p10). Проверен отдельный [стенд](../../experiments/music-bank/README.md), не продуктовая версия 1.4.0.

## Результат и решение

Из **16** целенаправленно выбранных пользовательских файлов **15 открылись**, получили SVG-партитуру, синтезированный PCM и ненулевой живой сигнал Web Audio в Edge. Один старый GTP v1.04 отвергнут с явным сообщением. Файл без расширения успешно распознан по содержимому как GP3.

В поддержанных файлах **66 партий**: для **61 непустой партии без общих каналов** отдельно проверены PCM при уровнях 1/0,25/0. Одна партия пустая. Четыре ударные партии в двух файлах связаны попарно каналом 9; их независимый микшер штатная alphaTab 1.9.0 не обеспечивает. Они отмечены блокерами и не включены в 61 успешную проверку.

Свободный проигрыватель технически осуществим, но **P10-01/R-024 не выполнены**. Группировка связанных партий и предупреждение стенда не считаются принятым продуктовым ограничением. До интеграции нужно решить независимость ударных и проверить предупреждения нотации/поддержку сложных файлов. Библиотека закреплена для исследования, окончательный выбор продуктового синтезатора этим результатом не утверждается.

Направление ритмической практики — метроном и ритм-секция по [R-025](../REQUIREMENTS.md#r-025). Фиксированный C–F–G–C пользователь не считает рабочим сценарием; сохранять его в будущем разделе как обязательный пресет не требуется. Нынешний продуктовый код сопровождения этой пробой не удалялся.

## Среда, файлы и изоляция

- Windows, Node **24.18.0**, Microsoft Edge **157.0.4341.42**, headless с заглушённым физическим выводом.
- Собственные package.json/lockfile стенда; **@coderline/alphatab 1.9.0**, MPL-2.0. Bravura — SIL OFL 1.1, поставленный sonivox.sf2 — Apache-2.0. Лицензии и атрибуция пакета сохранены; внешние CDN не используются.
- Ручной сервер — 127.0.0.1:4196; автоматические owned-серверы — 4197 и 4198, последовательно. Занятый порт даёт отказ. Пользовательский сервер на 4173, его профиль и IndexedDB не затрагивались.
- Сервер раздаёт только стенд, npm-ресурсы и выбранные файлы по ограниченному списку ID. Перед чтением проверяются размер и SHA-256. Музыкальные исходники остаются в пользовательской папке; PCM не сохраняется в Git, JSON или отдельные файлы.
- Папка содержит 48 602 файла / 1 359 983 201 байт: 25 458 GP4, 23 044 GP3, 59 GP5, 39 GTP, 1 GPX, 1 без расширения. Полное сканирование расширений не является импортом всего каталога.

Выборка не случайная: разные версии формата, ансамбли/сольные аранжировки, альтернативные версии песни, ударные, non-ASCII путь. Её размер **496 855 байт**. Имена и содержимое не считаются эталоном авторства/транскрипции; например один Enter Sandman расположен в папке Metal Molly. Точные относительные пути, SHA-256, причины отбора и сигнатуры — в [manifest](../../experiments/music-bank/sample-selection.json).

## Что именно проверялось

**Структура:** существование/границы путей, размер/SHA-256, байтовый импорт ScoreLoader, реальные tracks/masterBars, программы/строи/каналы. Отдельный файл без расширения не фильтруется до попытки разбора. Исходники не переписываются.

**Браузер и UI:** на каждом поддержанном файле есть фактические SVG-глифы, готовый синтезатор, движущийся tick и события музыкального курсора. Все звуковые контролы каждой партии переключались через видимый UI; отдельно выбиралась произвольная последняя видимая партия при сохранённом звуковом составе. Проверены start/pause/resume/stop и изменение скорости. Звучащие/видимые партии не привязаны к басу или обязательному порядку действий.

**Настоящий PCM:** для каждого поддержанного файла короткий смешанный экспорт ненулевой. Дополнительный runner изолировал каждую непустую партию без общих каналов, находил участок с атаками нот и рендерил уровни 1/0,25/0 в стерео при 44 100 Гц. Нулевой уровень даёт тишину, четверть — соответствующий RMS. Это экспорт синтезатора с явным AudioExportOptions.trackVolume, он не наследует live mute/solo/volume и не доказывает работу живых кнопок сам по себе.

**Живой выход:** initScript подключает дополнительный AnalyserNode к реальному AudioWorkletNode, сохраняя исходное соединение с AudioContext.destination. На каждом из 15 файлов получен ненулевой сигнал. В отдельной пробе выбрана гитара James Hetfield (Clean), program 27, а не бас: выключение всех инструментов даёт тишину; solo и уровни 1/0,2 проверяются по live-сигналу. Цикл определяется по фактическому возврату tick, пауза — по остановке времени и тишине, продолжение и seek — по восстановлению сигнала и движению аудиовремени.

**Ошибка диапазона:** неправильные такты во время игры приостанавливают проигрыватель, снимают прежний фрагмент/loop и блокируют старт до исправления либо выбора всей песни. Это исключает молчаливое продолжение прежнего корректного диапазона.

**Ресурсы и ошибки:** браузерные прогоны блокируют внешние запросы, используют новые контексты; pageerror и внешних HTTP-запросов нет. Показанные микшером группы общих каналов — подтверждённая граница штатного API, не имитация независимого звука.

## Обнаруженные ограничения

1. **Связанные ударные.** Solo Batterie и одна Billie Jean используют по две percussion-партии на канале 9. У alphaTab mute/solo/volume адресуют каналы. Простое переназначение на другой номер не принято: точный движок 1.9.0 также распознаёт/загружает ударные сэмплы по каналу 9. Для свободного микшера нужен проверенный адаптер/доработка синтезатора либо другой движок.
2. **Старый формат.** GTP v1.04 из выборки не поддерживается. Это честный отказ, а не успешно проигранная шестнадцатая песня. Остальные GTP всего банка не импортировались.
3. **Нотация и эффекты.** В реальном прогоне зарегистрированы fallback нестандартного bend, `No articulation found for percussion instrument NaN` и предупреждение о сжатом такте с возможным наложением символов. Они сохранены в browser raw; наличие SVG не означает корректность всех ударных обозначений и всех тактов. ID предупреждения означает текущую выбранную загрузку в момент сообщения; worker может ещё завершать прежний рендер. Два снимка просмотрены визуально, это выборочная QA, не приёмка всей партитуры.
4. **Каталог и контекст.** Нет индекса всех 48 тысяч файлов, долговечного доступа к папке, избранного, продуктового сохранения/восстановления, миграции схемы и интеграции с одним звуковым владельцем main. Быстрые конкурентные переключения во время render/MIDI load отдельно не принимались.
5. **Музыкальные границы.** Исходный строй и число струн сохраняются; разные инструменты не принудительно превращаются в EADG. Точность чужой транскрипции, все репризы/вольты/изменения темпа, отсутствие любых потерянных эффектов и оптимальная аппликатура не доказаны. UI диапазона использует первое вхождение указанных тактов.
6. **Физический звук.** Sonivox — небольшой учебный банк. Натуральность, комфорт тембров, работа реального баса/USB, сквозная задержка и акустическое восприятие требуют отдельного прослушивания/измерений. Физический вывод автоматического Edge заглушён; fake-device и физический вход не использовались.

## Воспроизведение и доказательства

Фактически выполнены из корня (первичная install также выполнялась внутри каталога стенда):

```powershell
npm.cmd --prefix experiments/music-bank ci --no-fund --no-audit
npm.cmd --prefix experiments/music-bank ls --depth=0
node experiments/music-bank/inspect.mjs
node experiments/music-bank/browser-check.mjs
node experiments/music-bank/mixer-check.mjs
node --check experiments/music-bank/app.mjs
node --check experiments/music-bank/inspect.mjs
node --check experiments/music-bank/server.mjs
node --check experiments/music-bank/browser-check.mjs
node --check experiments/music-bank/mixer-check.mjs
```

При разработке исправлены обработка отказа чтения локального файла, синхронизация действительно связанных звуковых контролов и отказ недопустимого диапазона. В проверке паузы добавлено ожидание фактического ответа асинхронного worker; синхронный вызов pause ещё не означает наступившую паузу. Первый вариант проверки seek ошибочно требовал сигнал в коротком окне от начала партитуры с паузами: итоговая проверка сначала проверяет Home, затем перемещается UI к вычисленному по MIDI звучащему такту (2,00 с / tick 3840). Точность и пороги звуковых проверок не ослаблялись.

Итог последовательного прогона: **18/18 browser checks и 17/17 mixer checks прошли**. В 18 включён один ожидаемый отказ GTP, а в 17 — проверки по файлам с явным исключением четырёх связанных и одной пустой партии. Число 61 относится к отдельным успешным PCM-проверкам партий, а не к 61 песне или полной приёмке продукта.
