# VIS-05 r1 «Метроном и ритм»

Отдельный интерактивный референс по [D-033](../../docs/DECISIONS.md#d-033) и [R-025](../../docs/REQUIREMENTS.md#r-025). [Карточка VIS-05](../../docs/design/screens/05-rhythm.md) сохраняет состав и состояния. **Статус: обе вкладки VIS-05 r1 утверждены пользователем 2026-11-08 и сохранены в проекте** — [запись утверждения](../../docs/design/screens/05-rhythm.md#approval-r1). [Проверка r1](../../docs/verification/RHYTHM_R1.md) прошла 9/9 групп; это не реализованный раздел основного продукта.

Две вкладки: **«Метроном»** с разными звуками, размером/акцентами/подразделением/swing и отдельно раскрываемыми немыми тактами/ростом темпа; **«Ритм-секция»** с собственными готовыми барабанными/перкуссионными паттернами и редактируемой 16-шаговой сеткой. По уточнению пользователя конструктор использует FL Studio-подобную логику строк инструментов, velocity, паттернов A/B/C/… и простой цепочки клипов; режимы **«Паттерн / Цепочка»** различаются. Оформление остаётся bass.study/r5, метроном — отдельной вкладкой. Предпрослушивание — native Web Audio. Это не полная DAW, копия UI, Piano roll или согласованные бас/аккордовые дорожки; готовые паттерны не являются библиотекой записей музыкантов.

## Локальный запуск

Из корня репозитория, PowerShell:

```powershell
node experiments/rhythm-reference/server.mjs
```

Открыть [метроном](http://127.0.0.1:4197) или [конструктор](http://127.0.0.1:4197/?view=rhythm). Сервер слушает только loopback; при занятом 4197 он отказывает, не останавливая чужой процесс. Для остановки собственного сервера — Ctrl+C в его терминале. Продуктовый сервер 4173 для просмотра этого референса не используется.

Для native JS/Web Audio этого стенда новые зависимости не требуются. Звук запускается явным действием пользователя; транспорт — **«Старт / Стоп»**, паузы нет. Скрытие вкладки останавливает preview до нового старта. Сохранение пишет только текущий паттерн и микшер в localStorage origin 4197, не целый проект A–H/цепочку. Основной продукт, его база/схема 7, данные занятий и настройки этой работой не меняются.

## Проверки и доказательства

Фактически выполнены из корня:

```powershell
node --check experiments/rhythm-reference/app.mjs
node --check experiments/rhythm-reference/server.mjs
node --check experiments/rhythm-reference/check.mjs
node experiments/rhythm-reference/check.mjs
```

Пройдены **9/9** групп (1 чистая и 8 браузерных, включая отдельный native Edge/CDP), 20 сочетаний геометрии. [Отчёт](../../docs/verification/RHYTHM_R1.md), [raw](../../docs/verification/RHYTHM_R1.json), просмотренные [метроном](../../docs/design/references/rhythm-r1-metronome-light.png), [конструктор светлый](../../docs/design/references/rhythm-r1-constructor-light.png) и [тёмный](../../docs/design/references/rhythm-r1-constructor-dark.png) сохраняют фактические результаты.

Проверены чистый план, настоящий браузерный PCM/живой сигнал, UI/курсор, обе темы, клавиатура, размеры окна и остановка. Рост темпа есть в UI/коде, но точная последовательность повышения не получила отдельного браузерного теста. Успех preview не подтверждает физическую задержку, натуральность тембра или продуктовую готовность. Пользователь утвердил обе вкладки референса и поручил сохранить их в проекте; это не разрешает автоматический перенос в приложение или выпуск новой версии.
