# Проба свободного музбанка

Отдельный локальный эксперимент P10-00 по [D-029](../../docs/DECISIONS.md#d-029) и [R-024](../../docs/REQUIREMENTS.md#r-024). Это не новая версия продукта и не его будущий утверждённый интерфейс. Любые партии доступны для выбора; видимость нот/TAB отделена от mute, solo и громкости. Звук синтезируется по партитуре, не является записью исполнителя.

Зависимость alphaTab **1.9.0** закреплена собственным package-lock.json; корневые зависимости не меняются. r1 использует воспроизводимо изменённый ESM из `generated-vendor`: уникальные виртуальные каналы каждой партии, включая ударные. `prepare-vendor.mjs` проверяет исходный SHA-256/версию/число замен и сохраняет MPL-2.0/атрибуцию, Bravura SIL OFL 1.1 и лицензию soundfont Apache-2.0. npm-пакет и исходные GP не переписываются. Generated-ресурсы игнорируются Git и заново создаются postinstall. Playwright используется из корневого package.json, все runtime-ресурсы загружаются локально.

## Запуск

Из корня репозитория, PowerShell:

```powershell
npm.cmd --prefix experiments/music-bank ci --no-fund --no-audit
node experiments/music-bank/inspect.mjs
node experiments/music-bank/server.mjs
```

Открыть http://127.0.0.1:4196. Сервер раздаёт только стенд, ресурсы библиотеки и 16 файлов из списка. Он не индексирует и не публикует всю музыкальную папку; слушает loopback, занятой порт не переиспользует. Для остановки — Ctrl+C в его терминале.

Два кандидата VIS-06 r1: `?sample=sample-08&layout=studio` — A «Студия», `?sample=sample-08&layout=reading` — B «Чтение». Варианты переключаются без смены песни. Ноты/TAB и видимые партии независимы от звука. Транспорт и доступ к микшеру остаются в окне, партитура/список инструментов прокручиваются внутри. Это референс для выбора, не утверждённый новый интерфейс продукта.

После изменения patch/helper явно выполнить `node experiments/music-bank/prepare-vendor.mjs` перед новым запуском. Изменённый core и worker/worklet должны происходить из одной подготовленной версии; ручное редактирование generated-ресурсов не является поддерживаемым способом изменения.

Путь коллекции берётся из sample-selection.json. Если папка перемещена, до запуска задать `$env:BASS_MUSIC_BANK_ROOT` с новым корнем. Относительные пути и SHA-256 должны совпасть. Музыкальные файлы не копируются в Git. В интерфейсе можно выбрать другой локальный файл вручную; эти файлы в зафиксированную приёмочную выборку не входят.

## Проверки

Выполнять последовательно из корня:

```powershell
node experiments/music-bank/browser-check.mjs
node experiments/music-bank/mixer-check.mjs
node experiments/music-bank/channels-check.mjs
node experiments/music-bank/channel-live-check.mjs
node experiments/music-bank/ui-check.mjs
```

Браузерные runners владеют портами 4197 / 4198 / 4201 / 4199 соответственно; channels-check работает в Node без браузера. Они не используют продуктовый 4173 и сервер ручного просмотра 4196. Браузеры — отдельный headless Edge с заглушённым физическим выводом и блокировкой внешних HTTP; каждый runner закрывает свои браузер/сервер. Занятые порты вызывают отказ; чужой процесс не завершается.

Результаты находятся в игнорируемой папке test-results/music-bank. Только проверенные JSON/снимки переносятся в [отчёт](../../docs/verification/MUSIC_BANK_PROBE.md). PCM в файлы не сохраняется: измеряются короткие окна, в JSON остаются статистики. PCM-экспорт и живой сигнал AudioWorklet проверяются отдельно; экспорт не наследует live-микшер.

## Границы

Старый GTP v1.04 из выборки не открывается. Штатный движок связывал ударные в двух файлах; это результат исторической [P10-00](../../docs/verification/MUSIC_BANK_PROBE.md). Исправление независимости, сравнение 65 непустых партий с одиночной штатной партией, live-проверки и новый UI описаны в отдельной [r1](../../docs/verification/MUSIC_BANK_R1.md). Исторические JSON не заменяются новыми исходами.

Виртуальные каналы предназначены только для внутреннего синтеза. Стандартный SMF/MIDI-экспорт с их номерами не поддерживается; соответствующей функции в UI нет. Смешанная ударная/мелодическая партия явно отклоняется адаптером. Все файлы каталога и все возможные эффекты не принимались по этой выборке.

В пробе нет полного каталога на 48 тысяч файлов, сохранения пресетов/занятий, миграции IndexedDB или интеграции со звуковым владельцем основного приложения. Выбор диапазона тактов с репризами использует первое вхождение; сложная навигация требует продуктовой модели. Качество звукового банка, чтение всех тактов, верность чужой транскрипции, физическая акустика и задержка не принимаются по этим автоматическим проверкам.
