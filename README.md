# bass_study

Личный локальный тренажёр для четырёхструнной бас-гитары E–A–D–G. Основной сценарий — занятия на Windows-компьютере в браузере с клавиатурой. Первый приоритет: ориентирование на грифе, ноты, ступени, гаммы, простые упражнения и ровный ритм.

Репозиторий: [fin4cast/bass_study](https://github.com/fin4cast/bass_study).

## Текущее состояние

Завершены P0–P5: документация, технические проверки, музыкальная модель, изучение грифа, экранные задания, проигрывание последовательностей и локальные данные. Можно сохранять пресеты, видеть раздельную историю экранных ответов и ручной практики, повторять ошибки и переносить настройки/историю JSON-копией.

Состояние сохранения и границы проверки — в [отчёте P5](docs/verification/P5.md); звук проверен на [P4](docs/verification/P4.md), задания — на [P3](docs/verification/P3.md), музыкальная модель и гриф — на [P2](docs/verification/P2.md). Отдельный стенд `experiments/p1` сохраняет исторические технические пробы. Экранные ответы и ручная отметка комфортного BPM имеют разные источники; время работы эталона не измеряет исполнение на басу. Звуковые проверки анализируют Web Audio и PCM; физические динамики и задержка аудиовыхода не измерялись.

Данные принадлежат этому браузерному профилю и адресу `http://localhost:4173`. Раздел «Мои занятия и настройки» содержит экспорт: браузерное сохранение не заменяет резервную копию. При недоступной базе приложение явно сообщает о работе только в памяти страницы.

## Локальный запуск

Из корня репозитория в PowerShell:

```powershell
npm.cmd ci --no-fund --no-audit
npm.cmd run build
npm.cmd start
```

Открыть [http://localhost:4173](http://localhost:4173). Нужны Node.js и первичная установка зависимостей; после сборки внешние ресурсы не требуются. Подробности — в инструкции разработки.
