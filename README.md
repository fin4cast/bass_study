# bass_study

Личный локальный тренажёр для четырёхструнной бас-гитары E–A–D–G. Основной сценарий — занятия на Windows-компьютере в браузере с клавиатурой. Первый приоритет: ориентирование на грифе, ноты, ступени, гаммы, простые упражнения и ровный ритм.

Репозиторий: [fin4cast/bass_study](https://github.com/fin4cast/bass_study).

## Текущее состояние

Завершены P0–P3: документация, технические проверки, музыкальная модель, изучение грифа, экранные задания и предпросмотр последовательностей. Можно проверить названия нот, найти ноту/все её позиции/ступень, получить раздельную сводку ответов и изучить маршрут упражнения. Звук, метроном и постоянная история ещё не интегрированы в приложение.

Проверенный результат и границы текущей версии — в [отчёте P3](docs/verification/P3.md); музыкальная модель и гриф ранее проверены на [P2](docs/verification/P2.md). Отдельный стенд `experiments/p1` сохраняет технические пробы звука и хранения; его механизмы ещё не заменяют продуктовые модули. Экранная сводка не измеряет игру на реальном басу и пока хранится только до перезагрузки.

## Локальный запуск

Из корня репозитория в PowerShell:

```powershell
npm.cmd ci --no-fund --no-audit
npm.cmd run build
npm.cmd start
```

Открыть [http://localhost:4173](http://localhost:4173). Нужны Node.js и первичная установка зависимостей; после сборки внешние ресурсы не требуются. Подробности — в инструкции разработки.
