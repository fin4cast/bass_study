# bass_study

Личный локальный тренажёр для четырёхструнной бас-гитары E–A–D–G. Основной сценарий — занятия на Windows-компьютере в браузере с клавиатурой. Первый приоритет: ориентирование на грифе, ноты, ступени, гаммы, простые упражнения и ровный ритм.

Репозиторий: [fin4cast/bass_study](https://github.com/fin4cast/bass_study).

## Текущее состояние

Завершены этапы P0 и P1: подготовлена документация, уточнён рабочий MVP и проверены ключевые технические механизмы. Есть изолированный стенд `experiments/p1`; продуктовый тренажёр ещё не реализован. Принятый объём и техническая основа закреплены в журнале решений.

В Edge 157 на Windows прошли 13 технических сценариев: локальная сборка без внешних ресурсов, звук и управление, скрытие вкладки, сохранение и атомарное восстановление. Это проверка стенда; приёмка всего MVP впереди. Подробности и ограничения — в [отчёте P1](docs/verification/P1.md).
