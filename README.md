# bass_study

Личный локальный тренажёр для четырёхструнной бас-гитары E–A–D–G. Работает в браузере на Windows-компьютере, управляется мышью и клавиатурой, ничего не отправляет в сеть. Первый приоритет — ориентирование на грифе, ноты, ступени, гаммы, простые упражнения и ровный ритм.

Репозиторий: [fin4cast/bass_study](https://github.com/fin4cast/bass_study).

## Что есть в приложении

- **Гриф** — изучение нот, ступеней и учебных форм, задания «найди/назови», последовательности под метроном.
- **Слух** — определение ступени трезвучия на слух.
- **Маршрут** — короткое занятие «гриф → слух → практика» на одном материале.
- **Метроном и ритм** — метроном с акцентами и подразделениями, ритм-секция с редактором шагов и библиотекой проектов.
- **Табулатура и ноты** — свои партитуры Guitar Pro (ноты, TAB, микшер) и аудиозаписи с A/B-повтором и скоростью.
- **Аудиовход** — диагностика уровня и высоты сигнала с инструмента.
- **Мои занятия** — история, пресеты, черновики ручной практики, экспорт и восстановление копии.

Данные хранятся в IndexedDB этого браузерного профиля для адреса `http://localhost:4173`. Браузерное хранилище не заменяет резервную копию — экспортируй её в «Моих занятиях». Свои партитуры и аудиофайлы в базу не копируются: после перезагрузки их нужно выбрать снова.

Экранные ответы, слуховой выбор, ручная отметка и таймер не оценивают игру на басу. Работа с настоящим басом через USB-интерфейс и сквозная задержка ещё не проверялись.

## Запуск

Нужен Node.js 22.12+ или 24. Из корня репозитория в PowerShell:

```powershell
npm ci
npm run build
npm start
```

Открыть [http://localhost:4173](http://localhost:4173) в Edge. После сборки сеть не нужна. Потом можно запускать [start.cmd](start.cmd) двойным щелчком: он только поднимает сервер, окно должно оставаться открытым, Ctrl+C завершает работу.

Записывать данные может одна вкладка. Вторая вкладка сообщит, что занятие уже открыто, и предложит проверить снова после закрытия первой.

Разработка и проверки — в [DEVELOPMENT](docs/DEVELOPMENT.md).
