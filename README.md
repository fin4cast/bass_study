# bass_study

Личный локальный тренажёр для четырёхструнной бас-гитары E–A–D–G. Основной сценарий — занятия на Windows-компьютере в браузере с клавиатурой. Первый приоритет: ориентирование на грифе, ноты, ступени, гаммы, простые упражнения и ровный ритм.

Репозиторий: [fin4cast/bass_study](https://github.com/fin4cast/bass_study).

## Текущее состояние

Подготовлена исходная документация проекта. Приложение, зависимости и средства его проверки пока не созданы. Состав MVP и архитектура описаны как предложения; подтверждённые пользователем решения перечислены в журнале решений.

Команд установки и запуска пока нет. Этот репозиторий на текущем этапе можно читать и развивать как документацию.
