# bass_study

Личный локальный тренажёр для четырёхструнной бас-гитары E–A–D–G. Основной сценарий — занятия на Windows-компьютере в браузере с клавиатурой. Первый приоритет: ориентирование на грифе, ноты, ступени, гаммы, простые упражнения и ровный ритм.

Репозиторий: [fin4cast/bass_study](https://github.com/fin4cast/bass_study).

## Текущее состояние

Завершены P0–P2: документация, технические проверки, музыкальная модель и интерфейс изучения грифа. Можно выбирать тональность, гамму или трезвучие, фильтровать участок, переключать ноты/ступени и исследовать связи между позициями. Полный учебный цикл MVP разрабатывается следующими этапами.

P2 проверен 77 unit-тестами и 15 браузерными сценариями в Edge 157 на Windows; [результаты и ограничения](docs/verification/P2.md). Отдельный стенд `experiments/p1` сохраняет 13 технических проверок звука и хранения; его механизмы ещё не заменяют продуктовые модули.

## Локальный запуск

Из корня репозитория в PowerShell:

```powershell
npm.cmd ci --no-fund --no-audit
npm.cmd run build
npm.cmd start
```

Открыть [http://localhost:4173](http://localhost:4173). Нужны Node.js и первичная установка зависимостей; после сборки внешние ресурсы не требуются. Подробности — в инструкции разработки.
