# bass_study

Личный локальный тренажёр для четырёхструнной бас-гитары E–A–D–G. Основной сценарий — занятия на Windows-компьютере в браузере с клавиатурой. Первый приоритет: ориентирование на грифе, ноты, ступени, гаммы, простые упражнения и ровный ритм.

Репозиторий: [fin4cast/bass_study](https://github.com/fin4cast/bass_study).

## Текущее состояние

Текущая версия — **1.3.0**; принятый программный объём P0–P7 выполнен в проверенных границах Windows/Edge. К грифу, шести типам заданий, последовательностям, слуху, активному маршруту и сопровождению C–F–G–C добавлены ноты/TAB существующей последовательности, личные WAV/MP3 и диагностический аудиовход. Данные/JSON до 64 МиБ используют схему 5 и принимают версии 1/2/3/4. Экранный ответ, слуховой выбор, ручная отметка, таймер и приблизительная высота входа не оценивают исполнение на басу.

Новый результат и его пределы — в [P7-04–06](docs/verification/P7-04-06.md); сопровождение — в [P7-03](docs/verification/P7-03.md), слух/маршрут — в [P7-01/02](docs/verification/P7-01.md), базовая приёмка — в [P6](docs/verification/P6.md), годовая история — в [P7-00](docs/verification/P7-00.md). Первое чтение большой истории всё ещё может задерживать страницу. `experiments/p1` сохраняет исторические пробы. Web Audio/PCM и синтетический вход проверены отдельно от физических динамиков, настоящего баса/USB и сквозной задержки.

Личные аудиофайлы остаются в памяти текущей страницы: JSON хранит только метаданные, после reload/restore их нужно выбрать снова. Изменение скорости дорожек меняет и высоту. Аудиовход подключается только по кнопке, не выводится на динамики и показывает исследовательскую оценку одного сигнала; калибровка настоящего инструмента ещё не проводилась.

Данные принадлежат этому браузерному профилю и адресу `http://localhost:4173`. Раздел «Мои занятия и настройки» содержит экспорт: браузерное сохранение не заменяет резервную копию. При недоступной базе приложение явно сообщает о работе только в памяти страницы.

## Локальный запуск

Из корня репозитория в PowerShell:

```powershell
npm.cmd ci --no-fund --no-audit
npm.cmd run build
npm.cmd start
```

Открыть [http://localhost:4173](http://localhost:4173). Нужны Node.js и первичная установка зависимостей; после сборки внешние ресурсы не требуются. Подробности — в инструкции разработки.

После этих шагов можно запускать [start.cmd](start.cmd) двойным щелчком, затем открывать тот же адрес в Edge. Окно сервера должно оставаться открытым; Ctrl+C завершает работу. Launcher не выполняет установку/сборку. Не открывать второе занятие для параллельной записи: приложение оставляет право одной вкладке и объясняет, как передать его другой.

## Следующий шаг

Незавершённых задач принятого программного объёма в [плане](docs/PLAN.md) нет. Следующий полезный шаг — личное занятие и отдельная калибровка баса/интерфейса по [протоколу](docs/verification/P7-04-06.md#протокол-следующего-испытания-с-настоящим-басом). Её результаты помогут выбрать дальнейшие изменения; SRS, редакторы, time-stretch и автоматический аудиозачёт остаются отдельными идеями.

Статусы требований определены в [требованиях](docs/REQUIREMENTS.md), задач — в [плане](docs/PLAN.md), решений — в [журнале](docs/DECISIONS.md). Дата подготовки исходной документации: 8 ноября 2026 года.
