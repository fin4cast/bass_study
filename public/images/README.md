# Фотография баса для бокового меню

`bass-headstock.webp` — декоративная фотография для утверждённого оформления **«Крупный акцент»** в обеих темах. Визуальные условия переноса — в [карточке оболочки](../../docs/design/screens/00-sidebar-accent.md), основание — [D-030](../../docs/DECISIONS.md#d-030).

## Источник

Источник фотографии — **Soundsation**, страница инструмента [Electric bass with roasted maple fretboard and neck — 4 strings](https://www.soundsationmusic.com/en/280885-electric-bass-with-roasted-maple-freboard-and-neck-4-strings). Использован [оригинал PNG 911×2000 px](https://www.soundsationmusic.com/storage/50f7b7e59e6fabb623c78549f3684f0a007ab6f8/image.png).

Проект не заявляет собственное авторство исходной фотографии. Отдельная лицензия на неё в этом документе не установлена; свободная лицензия изображения не заявляется.

## Подготовка и поставка

Использован тот же снимок, что в согласованном референсе, в исходном большем разрешении. Инструмент не перерисовывался: геометрия головки, четыре колка, струны и прочие детали сохранены. Белый внешний фон отделён плавным контуром. Согласованный тон — насыщенность **0,68**, затем gamma с показателем **1,16** в sRGB — запечён вместе с прозрачностью.

Пустые поля обрезаны по прямоугольнику исходника **(197, 212, 568, 1788)**: координаты x/y левого верхнего угла и ширина/высота в пикселях. Ресурс упакован в **lossless WebP с альфа-каналом** без дополнительного уменьшения. Нижнее плавное исчезновение грифа в файл не запечено: его задаёт CSS по доступной высоте меню.

Обе темы загружают один локальный ресурс. Для его показа не требуются сетевой запрос к производителю, отдельная маска или SVG-фильтр во время работы приложения.
